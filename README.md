# 版本1 · 智能环境监测设备 —— 使用说明

> 适用对象：拿到本设备进行部署、使用、二次接入云端的商家/用户
> 系统组成：**采集端（LoRa 发送） + 接收/显示端（WiFi + 巴法云 MQTT） + 微信小程序**

## 一、产品简介

本设备是一套**多传感器环境监测系统**，实时采集现场温度、湿度、CO₂ 浓度、光照强度、土壤湿度，并通过云端转发到微信小程序，手机随时可看、可控。

```
┌──────────┐   LoRa(10字节)   ┌──────────────┐   WiFi/MQTT   ┌──────────────┐
│  采集端    │ ──────────────▶ │  接收/显示端   │ ────────────▶ │  巴法云云端    │
│ (传感器)   │                 │ (WiFi+MQTT)   │               │ bemfa.com    │
└──────────┘                 └──────────────┘               └──────┬───────┘
                                                                    │
                                             微信小程序 ────────────┘
                                             (实时数据/控制/预警)
```

| 项目 | 说明 |
|---|---|
| 传感器 | 温度、湿度、CO₂ 浓度、光照、土壤湿度 |
| 无线传输 | LoRa（采集端 → 接收端） |
| 联网方式 | WiFi（接收端 ESP12-F 模块，2.4GHz） |
| 云平台 | 巴法云（bemfa.com），MQTT 3.1.1 协议 |
| 数据上报 | 每 **30 秒**上报一次 |
| 手机端 | 微信小程序（实时查看 / 灯控开关 / 微信预警） |

## 二、快速上手（三步）

拿到设备后，按以下三步即可让手机看到实时数据：

1. **改代码 + 烧录**：把「巴法云私钥」和「你家 WiFi」写进接收端固件，重新编译烧录（见 [第 3 节](#三修改代码中的巴法云私钥)、[第 4 节](#四修改-wifi-热点信息)、[第 6 节](#六编译与烧录)）。
2. **巴法云准备**：注册巴法云、获取私钥、创建主题（见 [第 7 节](#七巴法云控制台准备)）。
3. **小程序查看**：导入小程序、填同样的私钥、添加设备主题（见 [第 8 节](#八微信小程序实时查看数据)）。

> ⚠️ 最关键的一点：**固件里的私钥、巴法云控制台的账号、微信小程序里填的私钥必须是同一个**，主题名也必须完全一致，三者才能对上。

## 三、修改代码中的巴法云私钥

### 文件位置

```
demo1_lora_recv_schduler/
└── User/
    └── bsp/
        └── esp_mqtt.h        ← 在这里改私钥
```

### 修改步骤

用文本编辑器（推荐 VS Code）打开 `User/bsp/esp_mqtt.h`，找到这一段（约第 60 行）：

```c
/**
 * @brief 巴法云用户私钥(UID)
 * 在巴法云控制台获取，作为MQTT客户端ID，用于身份验证
 */
#define BAFA_UID "f6ebbe67c542c01ed1d796349dfd9a85"
```

把引号里的 `f6ebbe67c542c01ed1d796349dfd9a85` **替换成你自己的巴法云私钥**，例如：

```c
#define BAFA_UID "a1b2c3d4e5f60718293a4b5c6d7e8f90"
```

### 说明

- 巴法云私钥就是你的**用户唯一标识（UID）**，获取方式见 [第 7 节](#七巴法云控制台准备)。
- 固件用这个私钥作为 **MQTT 客户端 ID**（`MQTT_CLIENTID = BAFA_UID`），巴法云以此识别设备，**无需用户名和密码**。
- 同一把私钥下创建的设备主题互不干扰；不同商家务必使用各自的私钥，避免数据串号。

## 四、修改 WiFi 热点信息

### 文件位置

```
demo1_lora_recv_schduler/
└── User/
    └── bsp/
        └── esp.h             ← 在这里改 WiFi
```

### 修改步骤

打开 `User/bsp/esp.h`，找到这段（约第 55 行）：

```c
/**
 * @brief WIFI热点配置
 * 根据实际网络环境修改
 */
#define WIFI_SSID         "LWH"
#define WIFI_PASSWORD     "88888888"
```

改成现场可用的热点：

```c
#define WIFI_SSID         "你家路由器的WiFi名称"
#define WIFI_PASSWORD     "你的WiFi密码"
```

### 说明

- 设备只支持 **2.4GHz** WiFi，**5GHz 热点连不上**，请确认路由器开了 2.4G 频段。
- WiFi 名和密码**不要出现中文字符**（部分模块对中文 SSID 兼容性差），建议纯英文数字。
- 改完需要重新编译烧录才会生效。

## 五、设备主题与数据格式

设备上报与接收都通过**巴法云主题**完成，主题名在 `User/bsp/esp_mqtt.h` 中定义：

| 宏定义 | 主题名（默认） | 方向 | 内容格式 | 小程序设备类型 |
|---|---|---|---|---|
| `BAFA_TOPIC_HUMITURE` | `humiture004` | 上报 | `#28.0#57.6`（#温度#湿度） | 温湿度 |
| `BAFA_TOPIC_CO2` | `co2004` | 上报 | `523`（ppm 纯数字） | CO2浓度 |
| `BAFA_TOPIC_PHOTORES` | `photores004` | 上报 | `124`（光照 lux 纯数字） | 光敏电阻 |
| `BAFA_TOPIC_SOIL` | `soil004` | 上报 | `65`（湿度百分比纯数字） | 土壤湿度 |
| `BAFA_TOPIC_LED` | `light002` | 接收 | `on` / `off` | 灯控开关 |

**只要把主题名保持一致，基本不用改这几行。** 如果一定要自定义主题名，请同步做三件事：

1. 修改 `esp_mqtt.h` 里对应的 `BAFA_TOPIC_xxx` 宏；
2. 到巴法云控制台创建**同名**主题；
3. 在微信小程序「管理」页添加**同名**设备并选择对应类型。

> 注意：上报主题（humiture/co2/photores/soil）**只发布、不订阅**；接收端只订阅控制主题 `light002`，用于接收小程序下发的 `on/off` 指令点亮/熄灭 LED。若自行订阅了上报主题，会收到自己发布的数据（日志会打印"未识别的 on/off 指令"）。

## 六、编译与烧录

### 环境要求

- Keil MDK5（uVision5），已安装 **STM32F1xx 器件包**
- 下载器：ST-Link（或 J-Link），用于烧录
- 芯片型号：**STM32F103C8T6**

### 步骤

1. 打开工程：双击 `MDK-ARM/demo.uvprojx`（在 Keil 中打开）。
2. 工具栏选择目标 `demo`（STM32F103C8）。
3. 点击 **Build（F7）** 编译，确认 `0 Error(s)`。
4. 用 ST-Link 连接板子（SWD 接口），点击 **Download（F8）** 烧录。
5. 上电后可通过串口（波特率 **115200**）查看运行日志，例如：
   ```
   [MQTT] (5/9) 连接 WiFi SSID=xxx...
   [MQTT] MQTT CONNECT成功
   [MQTT] 主题订阅成功 (light002)
   [MQTT][发布] #27.1#65.0 -> humiture004
   [MQTT][发布] 0 -> co2004
   ```
   出现 `MQTT CONNECT成功` 与 `[MQTT][发布]` 即表示已上云成功。

## 七、巴法云控制台准备

1. **注册登录**：打开 [cloud.bemfa.com](https://cloud.bemfa.com)，用邮箱注册（也可微信扫码登录）。
2. **获取私钥（UID）**：登录后控制台首页即可看到你的 **私钥/UID**（一串 32 位十六进制），复制保存。
   - 把这个私钥填进固件 `BAFA_UID`（[第 3 节](#三修改代码中的巴法云私钥)）和微信小程序「我的」页（[第 8 节](#八微信小程序实时查看数据)）。
3. **创建主题**：在控制台「创建主题」处分别创建：
   - `humiture004`、`co2004`、`photores004`、`soil004`（上报）
   - `light002`（灯控，名称后三位 `002` 会被识别为灯泡设备）
   - 主题名仅限字母/数字。
4. **（可选）绑定微信**：控制台 →「绑定微信」扫码授权并关注公众号「巴法云」，用于接收设备超标预警通知。

## 八、微信小程序实时查看数据

### 8.1 导入小程序

1. 打开**微信开发者工具**，选择「导入项目」。
2. 目录选择：`d:\h5_app\bamfa\code`
3. AppID 选择你自己的小程序 AppID（或用测试号）。
4. 导入后即可预览；真机预览需在开发者工具勾选「不校验合法域名」（或按 [8.5 节](#85-真机域名配置)配置域名）。

### 8.2 配置私钥并连接

1. 底部导航切到「**我的**」页。
2. 在「MQTT 连接配置」里把 **私钥（ClientId）** 填成**与固件一致**的巴法云私钥（默认已预填占位值，务必改成你自己的）。
3. 点「**保存配置**」→ 点「**连接**」，顶部状态显示「已连接」即可。

### 8.3 添加设备

1. 切到「**管理**」页，点「**＋ 添加设备**」。
2. 填写：
   - **主题**：与固件一致，如 `humiture004`
   - **设备名称**：随意，如「客厅温湿度」
   - **设备类型**：按 [第 5 节](#五设备主题与数据格式) 表格选择对应类型（温湿度/CO2/光敏/土壤/灯控）
3. 保存后，切到「**设备**」首页即可看到卡片，显示**实时数据**与**在线状态**（在线判定 = 最近收到数据在 2 分钟内）。

### 8.4 查看与控制

- **首页（设备）**：卡片式展示所有设备，实时数值、在线/离线、最近更新时间；下拉可刷新。
- **详情页**（点设备卡片进入）：
  - 灯控设备：开关切换 → 向 `light002/set` 发送 `on/off` → 设备 LED 亮灭。
  - 传感器设备：显示温度/湿度/CO₂/光照/土壤数值，可「发送指令」调试，可查看消息记录。
  - **微信预警**：开启开关并设置阈值（如 CO₂ 上限 1000ppm），超标自动推送微信通知（需先在巴法云绑定微信）。

### 8.5 真机域名配置

真机调试/发布时，需要在**微信公众平台 → 开发管理 → 开发设置 → 服务器域名**里配置：

| 类型 | 域名 |
|---|---|
| request 合法域名 | `https://apis.bemfa.com`（微信预警推送用） |
| socket 合法域名 | `wss://bemfa.com:9504`（MQTT 连接用） |
